# SliceDimensionCard 图像独立窗口设计

## 目标

为 `SliceInterface` 中的每个 `SliceDimensionCard` 增加统一的右键操作：当卡片已有图像时，在鼠标位置显示组件库 `CommandBarView`，并提供一个“独立显示”图标操作。该操作使用独立的 `FluentWidget` 窗口显示当前图像快照，便于不同卡片或不同时刻的图像并排对比。

## 已确认的交互约束

- 卡片无图像或图像为空时，右键点击无反应。
- 卡片有图像时，右键显示仅包含一个“独立显示”操作的 `CommandBarView`。
- 每个卡片同一时刻最多拥有一个独立窗口；重复触发时恢复、置顶并激活已有窗口。
- 不同卡片允许同时打开各自的独立窗口。
- 窗口保存打开瞬间的图像快照；卡片后续更新不会改变已打开窗口的内容。
- 独立窗口关闭后，该卡片才可再次创建新的快照窗口。
- 窗口为非模态窗口，支持同时观察和比较。

## 架构与职责

### `SliceDimensionCard`

卡片组件负责与自身状态直接相关的交互：保存当前源图像副本、处理右键事件、构建 `CommandBarView`，以及维护本卡片唯一的独立窗口引用。此边界避免 `SliceInterface` 为十个卡片重复绑定事件或维护窗口字典。

卡片构造参数增加明确的窗口标题文本。标题由页面组合卡片时传入，用于区分“原始图像”和“聚类结果”，不通过对象名或父控件结构反向推断。

### 图像快照窗口组件

在 `ui/components` 中新增独立组件，继承组件库 `FluentWidget`。它只负责：

- 深拷贝并持有传入的 `QImage` 快照；
- 设置窗口标题和合理的初始尺寸；
- 在窗口尺寸变化时保持宽高比并平滑缩放图像；
- 提供标准 Fluent 无边框标题栏和窗口按钮。

不使用带导航栏和堆栈页面的 `FluentWindow`，因为单幅图像窗口不需要导航结构。

### `SliceInterface`

页面仍作为组合宿主，只在创建十个卡片时传入对应窗口标题，不承载右键菜单、窗口生命周期或图像绘制逻辑。

## 组件库用法

根据 Context7 返回的官方文档与仓库内置 qfluentwidgets 源码：

- 使用 `CommandBarView.addAction(Action(...))` 添加操作；
- 使用 `Flyout.make(view, global_position, parent_window)` 在右键全局坐标显示命令栏；
- 使用 `FluentWidget` 作为独立无边框窗口基类；
- 命令栏 Flyout 关闭时自动释放，快照窗口由卡片保留强引用。

## 数据与生命周期

1. `set_image()` 将图像分别深拷贝到卡片和现有显示标签中。
2. 右键事件先检查卡片图像是否存在且非空；不满足条件时立即返回。
3. 有图像时创建 CommandBar，并将“独立显示”Action 连接到卡片私有方法。
4. Action 触发时：
   - 窗口引用有效：调用 `showNormal()`、`raise_()`、`activateWindow()`；
   - 窗口不存在：复制卡片当前图像，创建并显示快照窗口。
5. 窗口 `destroyed` 信号清空卡片引用。
6. 卡片后续 `set_image()` 只更新卡片，不通知已打开的快照窗口。

## 异常与边界处理

- 未设置图像和 `QImage.isNull()` 使用相同行为：右键无反应。
- 窗口最小化后重复触发，应恢复为普通状态并激活。
- 清理窗口引用时不依赖对已销毁 Qt 对象的方法调用。
- 不修改现有 QSS，也不新增图标资源，优先使用组件库图标枚举。

## 测试与验证

按 RED→GREEN 顺序增加聚焦测试：

- 无图像右键不创建 CommandBar；
- 有图像右键创建仅含一个操作的 CommandBar；
- 首次触发创建窗口并保存图像快照；
- 同一卡片重复触发只激活原窗口；
- 卡片图像更新不改变窗口快照；
- 窗口关闭后允许重新创建；
- 不同卡片可以同时持有不同窗口。
