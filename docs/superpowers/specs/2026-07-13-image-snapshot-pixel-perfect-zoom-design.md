# 图像快照窗口像素无损倍率显示设计

## 目标

消除 `ImageSnapshotWindow` 对雷达栅格图像的平滑插值模糊，使用组件库 `ImageLabel` 与 `Slider` 提供 1～10 倍整数倍率显示，保证所有源像素均被保留。

## 已确认约束

- 输入图像尺寸只有 `500×250` 和 `400×80` 两种。
- 默认倍率为 3 倍，最小 1 倍，最大 10 倍，步长为 1。
- 只允许整数倍最近邻放大，不使用平滑插值，不缩小到 1 倍以下。
- 独立窗口仍为无 parent 的顶层 `FluentWidget`，保留移动、最小化、最大化、关闭、外轮廓及单卡片单窗口行为。
- 窗口展示的是打开瞬间的图像快照，不跟随卡片后续刷新。

## 组件结构

### 像素无损图像标签

新增 `PixelPerfectImageLabel`，继承组件库 `ImageLabel`。继续使用 `ImageLabel.setImage()`、图像状态和尺寸接口，仅覆盖绘制事件，关闭 `SmoothPixmapTransform` 并使用最近邻方式把源图像绘制到整数倍目标矩形。

该子类只解决组件库 `ImageLabel.paintEvent()` 固定使用 `SmoothTransformation` 与像素无损需求冲突的问题，不复制组件库其他行为。

### 图像滚动区域

使用无边框 `QScrollArea` 承载 `PixelPerfectImageLabel`：

- 图像标签尺寸始终严格等于 `原图宽高 × 当前倍率`；
- 图像小于 viewport 时居中；
- 最大化后图像仍大于 viewport 时通过滚动条查看；
- 不使用 `setWidgetResizable(True)`，避免滚动区域反向压缩图像。

### 倍率控制

底部控制区使用组件库水平 `Slider`：

- `minimum = 1`；
- `maximum = 10`；
- `singleStep = 1`；
- `value = 3`；
- `valueChanged` 连接到窗口倍率更新方法；
- 使用文本标签显示当前倍率，例如 `3×`。

## 窗口尺寸规则

窗口目标尺寸由以下内容组成：

- 图像目标尺寸：`源图像尺寸 × 倍率`；
- 左右内容边距；
- Fluent 标题栏高度；
- Slider 控制区高度和上下间距；
- 窗口外轮廓占用。

倍率变化时同步更新窗口尺寸：

1. 目标尺寸不超过当前屏幕 `availableGeometry()` 时，窗口保持或恢复普通状态，并调整为计算出的目标尺寸。
2. 目标尺寸超过屏幕可用区域时，窗口切换为最大化；图像保持当前整数倍率，通过滚动条查看完整内容。
3. 最大化后降低倍率，若目标尺寸重新落入可用区域，窗口恢复普通状态并缩放到对应目标尺寸。

默认 3 倍时：

- `500×250` 图像显示为 `1500×750`；
- `400×80` 图像显示为 `1200×240`；
- 窗口在上述图像尺寸基础上增加适当边距和控制区空间。

## 数据与绘制规则

- `ImageSnapshotWindow` 继续深拷贝源 `QImage`。
- 每次倍率改变只更新显示尺寸，不修改 `_snapshot_image`。
- 每个源像素在 N 倍显示时映射为颜色完全一致的 `N×N` 像素块。
- 禁止 `SmoothTransformation`、任意比例适配和缩小采样。

## 测试设计

按 RED→GREEN 覆盖：

- 窗口使用 `ImageLabel` 子类和组件库 `Slider`；
- Slider 范围为 1～10，默认值为 3；
- 默认图像标签尺寸严格等于原图 3 倍；
- 1、3、10 倍下图像标签尺寸均为原图整数倍；
- 棋盘或离散点图像放大后，每个源像素形成颜色一致的整数像素块；
- 倍率变化不改变快照源像素；
- 目标尺寸可容纳时窗口同步调整尺寸；
- 目标尺寸超出可用屏幕时窗口最大化并保留完整图像尺寸；
- 从超大倍率降回可容纳倍率时恢复普通窗口尺寸；
- 原有独立窗口、轮廓、关闭重建和单窗口测试继续通过。

## 组件库依据

Context7 官方文档确认：

- `ImageLabel` 支持 `QImage` / `QPixmap` 构造、`setImage()` 和 `setScaledSize()`；
- `Slider` 继承 `QSlider`，可使用标准范围、步长、默认值和 `valueChanged` API。

本地组件库源码进一步确认 `ImageLabel.paintEvent()` 固定使用 `SmoothTransformation`，因此必须通过轻量子类覆盖绘制策略才能满足像素无损要求。
